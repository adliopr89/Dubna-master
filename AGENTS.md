# Мастера Дубны — Telegram Mini App + бот

Записи клиентов к мастерам: клиент ↔ мастер по ссылке/коду, рабочие дни с перерывами,
заявка → мастер назначает время (бронь с таймером) → клиент подтверждает, отмены,
напоминания, уведомления в миниаппе и через бота.

## Архитектура

- Хранилище — **JSON-файл** `data/db.json` (вместо БД). Сидится из `app/webapp/seed.js`.
- `app/webapp/` — Mini App, один `index.html` (ванильный JS) + `seed.js` (общий с сервером).
  Два режима: `/api/state` отвечает → общий стейт через сервер; нет → localStorage (статика/Pages).
- `app/server/` — `node index.js`: статика + `GET/PUT /api/state` + бот (long polling, без зависимостей).
- `docs/` (в **корне ветки** `mastera-dubny`) — статическая сборка для GitHub Pages, генерируется
  `node "Мастера Дубны/build-static.js"`, руками не править.
- Токен бота — `../../Проекты/MasterBot.txt` или `data/bot.token` или env `MASTER_BOT_TOKEN`.
  **Никогда не коммитить.**

## Команды

```powershell
node "Мастера Дубны/app/server/index.js"   # app http://127.0.0.1:8095/ + бот
node "Мастера Дубны/build-static.js"       # сборка docs/ для Pages
```

## Связность бот ↔ приложение

- `/start mNNNN` — заявка клиента к мастеру; заявки из миниаппа тоже уходят мастеру
  сообщением с кнопками «Принять/Отклонить».
- Все события из `DB.notes` доставляются в Telegram тем, у кого есть `tgId`
  (ставится при первом `/start` по @username / telegram id).
- Каждые 3 с — доставка уведомлений и заявок; каждые 30 с — сгорание броней
  и напоминания по настройкам клиента (`rem.r30/r60/r1440` + свои `cust`).
